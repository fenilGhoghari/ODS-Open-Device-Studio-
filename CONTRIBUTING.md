# Contributing to Open Device Studio

Thank you for your interest in contributing to Open Device Studio!

We welcome contributions from developers of all experience levels.

## Ways to Contribute

- Report bugs
- Suggest new features
- Improve documentation
- Fix existing issues
- Create plugins
- Improve performance
- Add tests

## Development Setup

1. Fork this repository.
2. Clone your fork.
3. Create a new branch.

Example:

git checkout -b feature/serial-monitor

4. Make your changes.
5. Test your changes.
6. Commit using a meaningful message.
7. Open a Pull Request.

## Coding Guidelines

- Follow modern C++20 standards.
- Write clean and readable code.
- Keep functions focused.
- Add comments only when necessary.
- Document public APIs.

## Commit Message Format

Examples:

feat: Add MQTT Explorer

fix: Resolve serial reconnect issue

docs: Update installation guide

refactor: Improve plugin loader

## Pull Request Checklist

- Code builds successfully
- Tests pass
- Documentation updated
- No breaking changes
- Screenshots included (if UI changes)

Thank you for helping make Open Device Studio better!
