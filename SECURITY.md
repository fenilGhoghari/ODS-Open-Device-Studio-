# Security Policy

## Supported Versions

Currently only the latest release receives security updates.

## Reporting a Vulnerability

Please do NOT create a public GitHub Issue for security vulnerabilities.

Instead, contact:

ghogharifd@gmail.com

or

Open a private GitHub Security Advisory.

Please include:

- Description
- Steps to reproduce
- Affected version
- Possible impact

We will acknowledge reports within 72 hours.

Thank you for helping keep Open Device Studio secure.
